# Repository guidance
This repository supports PhD research, not a validated agronomic recommendation.
Read README.md and docs/research-plan.md before methodological work.
Use the existing checkout; cloud tasks are already isolated. Do not create worktrees
unless requested. Preserve data permissions and distinguish implemented baselines
from planned algorithms. Never invent results, citations, benchmark success or
approval of agronomic regimes. Test statistical invariants independently and record
seeds, budgets and failures. Keep large/generated/private data out of Git.
